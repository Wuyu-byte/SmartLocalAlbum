## 移动应用三项功能变更

### 1. 删除筛选功能
- 删除 `MetadataFilterView.swift` 文件
- 从 `HomeView.swift` 中移除"筛选"Tab（TabView 从 4 个 Tab 减为 3 个：首页/搜索/动态）

### 2. 智能搜索结果恢复完整交互（修正: 之前误解为"仅展示缩略图"）
- 浏览模式: 每个 SearchHitCard 由 NavigationLink 包裹 → 点击跳转 PhotoPreviewView 全屏预览
- 浏览模式: 长按 → 上下文菜单（选择/复制到剪贴板）
- 选择模式: 工具栏"选择"按钮切入，点击切换选中，工具栏变更为"全选"+"完成"
- 选择模式: 长按 → 上下文菜单（选择/取消选择 + 复制）
- 批量操作栏: 显示已选数量 + 批量删除按钮
- SearchHitCard 恢复大缩略图 (target 320x320, grid minimum 110)
- 支持 isSelectMode/isSelected 参数，选中时显示蓝色对勾 + 半透明覆盖层

### 3. 中文输入自动翻译为英文搜索
- 引入 `import Translation`（Apple Translation 框架）
- 实现 `containsCJKCharacters()` 检测中日韩字符
- 通过 `.translationTask` + `TranslationSession` 实现本地翻译（iOS 17.4+）
- 中文输入 → 后台翻译为英文 → 用英文文本编码搜索
- 用户界面始终显示中文原文，翻译过程对用户透明
- 翻译失败时自动回退到原文搜索
- 搜索栏下方显示"正在翻译为英文..."状态指示
